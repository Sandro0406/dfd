##### Integración continua de los Web Services

Como parte de la automatización previa al despliegue de los Web Services, se configuró en `machineguard-core-api` y `machineguard-edge-api` el workflow `CI` de GitHub Actions (`.github/workflows/ci.yml`). El workflow ejecuta la batería completa de pruebas en cada `push` a `main`, `develop`, `feature/**`, `release/**` y `hotfix/**` y en cada pull request hacia `develop` y `main`, de modo que solo se integren y desplieguen cambios que superan las pruebas. Cada ejecución publica sus reportes como artefactos descargables.

| Elemento | `machineguard-core-api` | `machineguard-edge-api` |
|---|---|---|
| Workflow | `.github/workflows/ci.yml` | `.github/workflows/ci.yml` |
| Entorno | Ubuntu, Temurin JDK 21, caché de Maven | Ubuntu, Python 3.12, caché de pip |
| Acciones utilizadas | `actions/checkout@v7`, `actions/setup-java@v6`, `actions/upload-artifact@v7` | `actions/checkout@v7`, `actions/setup-python@v7`, `actions/upload-artifact@v7` |
| Comando | `mvn -B verify` | `python -m pytest -v --junitxml=reports/junit.xml --cucumberjson=reports/cucumber.json` |
| Artefactos | `cucumber-report`, `surefire-reports` | `test-reports` |
| Primera ejecución exitosa | [#1](https://github.com/MachineGuard/machineguard-core-api/actions/runs/37661552258), 2026-10-07 | [#1](https://github.com/MachineGuard/machineguard-edge-api/actions/runs/37661558175), 2026-10-07 |

En la primera ejecución, GitHub Actions advirtió que las versiones utilizadas de `actions/checkout`, `actions/setup-java`, `actions/setup-python` y `actions/upload-artifact` se basaban en Node.js 20, que está en desuso en los runners de GitHub. Se actualizaron a sus versiones basadas en Node.js 24 y las siguientes ejecuciones finalizaron sin advertencias.
